# Raw data (not committed)

Download **Naukri Jobs Dataset** (file `naukri_data_scientist.csv`) from Kaggle:
https://www.kaggle.com/datasets/muhammetakkurt/naukri-jobs-dataset

Save it here as `data/raw/naukri_data_scientist.csv`, then run `python -m src.clean`.
Check the dataset's licence on its Kaggle page before you share the raw file.
